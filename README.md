# Design tests

Веб-платформа для подготовки к экзамену по дисциплине "Информационные технологии и компьютерная графика".

## Что внутри

- React + TypeScript + Vite
- TailwindCSS и Framer Motion
- React Router и React Query
- Node.js + Express + TypeScript
- SQLite через Prisma
- Локальная база вопросов в JSON и SQLite
- 1560 вопросов по 26 темам, доступных даже без backend
- Экзамен, практика, режимы повторения, мини-игры, статистика и админка
- Регистрация, вход и таблица лидеров
- Личные сообщения между зарегистрированными участниками рейтинга

## Запуск

```bash
npm install
npm run dev
```

Первый запуск автоматически:

- создаст `.env`, если его нет
- сгенерирует `data/questions.json`
- выполнит `prisma generate`
- применит схему SQLite
- заполнит базу вопросами

После этого приложение будет доступно:

- Frontend: `http://localhost:5173`
- Backend: `http://localhost:4000`

## Netlify

Для деплоя фронтенда на Netlify уже добавлены:

- `netlify.toml`
- SPA redirect на `index.html`
- publish directory `dist/client`

На Netlify приложение автоматически использует локальную JSON-базу и хранит профили, результаты, интервальные повторения и рейтинг в `localStorage`. Поэтому тесты, регистрация и статистика работают без отдельного сервера. При локальном запуске через `npm run dev` дополнительно используется Express + Prisma + SQLite.

Личные сообщения в статическом режиме также сохраняются в браузере. Для переписки между разными устройствами требуется опубликованный backend с общей базой данных.


## Структура

- `src/` - фронтенд
- `server/` - Express API и логика выборки вопросов
- `shared/` - общие типы
- `scripts/` - генерация JSON и bootstrap
- `prisma/` - Prisma schema и SQLite база
- `data/` - JSON база вопросов

## Админка

Админ-панель `/admin` доступна только авторизованному пользователю с ником `lonexnesss`. Она позволяет:

- добавлять вопросы
- редактировать вопросы
- удалять вопросы
- импортировать JSON
- экспортировать JSON

## Примечание

База вопросов и статистика хранятся локально. Никакие платные API не используются.
